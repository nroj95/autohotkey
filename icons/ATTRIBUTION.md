# Icon attribution

The icons in this directory use artwork from the FatCow Farm-Fresh Web Icons
3.9.2 set by FatCow.

The original artwork is licensed under Creative Commons Attribution 3.0
(CC BY 3.0).

### `pause-command-mode.ico`

Source artwork:

- `control_pause_blue.png` — 32x32

use by `pause-command-mode.ahk`.
